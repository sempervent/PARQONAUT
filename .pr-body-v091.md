## Summary

- Bounded streaming Parquet publication to S3 (multipart finalize fix; convert uses `write_parquet_batch_stream`, no whole-object buffer).
- Independent local/S3 source and sink routing for transform, stream convert, and fused specs.
- Authoritative **6×4** remote pipeline matrix on RustFS plus expanded `s3-integration` CI (`write_s3_roundtrip`, `remote_convert_s3`, `remote_pipeline_matrix`).
- Full **`just pipeline-s3-demo`** (CSV drift → S3 convert → fused rewrite/partition, zero intermediate objects).

## Architecture

```text
RecordBatch → Parquet encoder (blocking) → bounded byte channel (8) → multipart S3 → committed object
```

Memory scales with part size and channel depth, not output object size.
