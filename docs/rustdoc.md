# Rust API (rustdoc)

Library crates in this workspace are documented with **rustdoc**. The documentation site publishes the built index under:

```text
rustdoc/
```

(relative to the GitHub Pages site root).

End users normally interact through **`prqnt`** or **`/api/v1`**. Rust API docs are for contributors and integrators embedding crates.

Rebuild locally as part of `just docs-build`.
