## Independent review passes (Phase 7)

1. **Pass A — Rust correctness, ownership, and process lifecycle:** Reviewed `scan_execute.rs`, `batch_execute.rs`, `batch_bridge.rs`, `batch_ipc.rs`. Verified RAII `ChildGuard` / `Drop` cleanup, zero detached threads, bounded stderr draining, and UTF-8 safe truncation. No unresolved findings.
2. **Pass B — Python SDK & protocol compatibility:** Reviewed `python/parqonaut_plugins/src/parqonaut_plugins/{contracts.py,runner.py}` and `parqonaut-plugin-protocol`. Fixed `_read_stdin` boundary bug; `ruff` and `pytest` pass. No unresolved findings.
3. **Pass C — Durable jobs, cancellation, recovery, and persistence:** Reviewed `server_plugins.rs`, `service.rs`, `worker.rs`, `http_api_postgres.rs`. Verified pinned selection parity, pre-spawn revalidation, non-blocking cancellation, and Postgres token isolation. No unresolved findings.
4. **Pass D — Local/S3 data correctness and publication:** Reviewed `sink.rs`, `s3/write.rs`, `local.rs`, `local_parquet.rs`, `storage_routing.rs`, `fused_chain.rs`. Fixed commit-on-error race and post-commit `finish()` ordering. All four storage matrix legs and S3 cancellation/mid-stream failure tests pass against RustFS. No unresolved findings.
5. **Pass E — Security assumptions, identity, env vars, and API auth:** Reviewed `digest.rs`, `catalog.rs`, `path_safety.rs`, `env.rs`, `service/error.rs`. Closed `PARQONAUT_TEST_PG_URL` and `PYTHONSTARTUP` propagation, rejected symlinks in digest, sanitized HTTP error messages, and documented Python runtime outside digest scope in `docs/plugins.md`. No unresolved findings.
6. **Pass F — CI reproducibility, docs, and release acceptance:** Reviewed `.github/workflows/{ci.yml,plugin-integration.yml}`, `Justfile`, `scripts/plugin-{s3,server}-demo.sh`, `docs/`. Fixed `s3-integration` Python override and verified `just docs-check`. No unresolved findings.
