# PARQONAUT v0.12.0 Baseline Audit & Final Disposition

**Baseline commit:** `3f5afbefc29cfa55266b4af8dbe700df2a0b9ff5` (`main`, after PR #12 and PR #13)  
**Target milestone:** `v0.12.0` (Reliability, Distribution, and 1.0 Readiness)

## Baseline Inventory

- **Workspace crates:** 21 Rust crates (`parqonaut-types`, `parqonaut-workflow`, `parqonaut-core`, `parqonaut-report`, `parqonaut-plugin-protocol`, `parqonaut-plugin-host`, `parqonaut-columnar`, `parqonaut-storage`, `parqonaut-store`, `parqonaut-transform`, `parqonaut-stream`, `parqonaut-repair`, `parqonaut-orchestrator`, `parqonaut-app`, `parqonaut-service`, `parqonaut-client`, `parqonaut-tui`, `parqonaut-cli`, `parqonaut-bench`, `xtask`).
- **Python runtime:** `python/parqonaut_plugins` (`uv.lock`, `pydantic`, `pyarrow`).
- **Databases:** SQLite (WAL + `synchronous=NORMAL` + `foreign_keys=ON`, 9 migrations `20250415120000`–`20261117120000`) and PostgreSQL (3 migrations `20250415120000`–`20261117120000`).
- **Object storage:** Local filesystem + S3-compatible backend (tested against RustFS 1.0.0) with conditional creation/replacement and multipart streaming.
- **Public interfaces:** `prqnt` CLI, `/api/v1/*` OpenAPI 3.1 HTTP API + SSE stream, `/ui/` bundled web dashboard, `prqnt tui`, and plugin protocol v1.
